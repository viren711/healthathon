# 100 example queries for the oncology reference platform.

# One query per line; blank lines and #-comments are ignored, so this file can
# be fed straight to a script:
#
#     python scripts/ask_batch.py eval/queries.txt            # answer each one
#     python scripts/ask_batch.py --locate eval/queries.txt   # locate only, no LLM
#
# Groups 1-15 are organised to mirror the organ-system taxonomy in
# config/organ_systems.yaml, so each group also exercises the portal's
# left-hand section selector: pick "Genitourinary > Prostate" and the group 8
# questions should still answer while the group 5 ones should not.
#
# The last two groups are deliberate. A reference tool is only trustworthy if
# it behaves correctly on questions it CANNOT answer as well as on ones it
# can, so group 16 is expected to abstain and group 17 to refuse. If anything
# in group 17 returns an answer, that is a bug worth chasing.
